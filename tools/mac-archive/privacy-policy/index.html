Mac Archive

1. 使う人

このツールは、運営者本人の Google アカウントだけで使います。

2. アクセスする情報

このツールがアクセスするのは、Google ドライブのうち、このツールが作ったファイルとフォルダだけです（権限: drive.file）。ほかのファイル、メール、連絡先、カレンダーにはアクセスしません。

3. 使い道

運営者の Mac にあるファイルを Google ドライブに保管し、必要なときに戻すためだけに使います。

4. 保存場所

ログインの情報（Google が発行するトークン）は、運営者の Mac の中だけに保存し、ほかのサーバーには送りません。

5. 第三者への提供

第三者には提供しません。

6. Google API から受け取った情報の扱い

Google API から受け取った情報は、Google API Services User Data Policy（Limited Use の要件を含みます）に従って扱います。
