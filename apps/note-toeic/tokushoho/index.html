販売するもの

note（https://note.com/toeic_app）の「TOEIC攻略ラボ」で販売する有料記事（デジタルコンテンツ）です。

販売価格

各有料記事の購入画面に表示する価格です。

販売価格以外にかかる費用

インターネット接続に必要な通信料はお客様の負担です。

支払方法

note株式会社が提供する支払方法（クレジットカード、携帯キャリア決済、PayPay など）でお支払いいただけます。利用できる支払方法は、note の購入画面と、note のヘルプ「サービス別-対応している支払い方法」に従います。会員登録をせずに購入する場合は、利用できる支払方法が限られます。

支払時期

購入手続きの完了時にお支払いが確定します。実際に引き落とされる時期は、ご利用の決済方法の定めによります。

引渡時期

決済の完了後（購入完了画面の表示後）、すぐに記事の全文をお読みいただけます。会員登録をせずに購入した場合は、決済の完了後に、記事の内容が電子メールで送られます。

返品・返金

デジタルコンテンツの性質上、お客様のご都合による返品はお受けしていません。ただし、各有料記事は note の「購入者からの返金申請を受け付ける」設定で販売しており、購入から24時間以内であれば、note の購入履歴から返金を申請できます。返金の可否は note の審査によります。会員登録をせずに購入した記事は、返金の対象外です。くわしくは note のヘルプ「返金ルールとよくあるご質問」をご確認ください。法令上必要な場合はこの限りではありません。

動作環境

note を閲覧できる環境（ウェブブラウザまたは note のアプリ）でお読みいただけます。
